Colmar Academy is a responsive website designed. Built with **HTML** and **CSS**, this project focuses on creating a clean, perfect for practicing web development fundamentals. 

---

## 🚀 Features

- 🎓 Display a list of courses with course details
- 📱 Fully responsive design for desktop, tablet, and mobile

- **CSS** (with custom styles)
